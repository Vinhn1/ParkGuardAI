# Ảnh mẫu tham khảo

Đặt các hình ảnh mẫu bạn cung cấp vào thư mục này. Nên đặt tên file theo màn hình hoặc chức năng để dễ đối chiếu khi xây dựng giao diện.

Theo DEC-027, các ảnh hiện có chỉ là tham chiếu **cấu trúc**. Màu sắc, dữ liệu minh họa, tên người, trạng thái xử lý và chức năng xuất hiện trong ảnh không tự trở thành yêu cầu triển khai hoặc dữ liệu thật của ứng dụng.
